    2.ospf 术语

    ① 区域

    一.

    区域尽管我们自己设置的时候一般使用证书，但是实际表示的是一个类似 IP 的结构

    area 0  ==  area 0.0.0.0
area 1  ==  area 0.0.0.1

    这里最大可以到 255.255.255.255，也就是 4,294,967,296

    因此这里的 area ID 实际上只是整数的一种表示方式

    二.

    area 0是骨干区域，其余区域都是非骨干区域，并且所有非骨干区域到要与骨干区域相连

    ②Router-ID

    系统自动配置

    遵循原则：首先查看回环口，选择回环口中最大的IP作为route ID -> 如果未配置回环口，则选择物理接口的最大值

    但是，在eNSP的华为设备中，实际上是谁先被设置，谁就作为route ID
