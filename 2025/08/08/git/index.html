    .git文件结构介绍

    1. .git 目录结构

    在你的项目根目录执行：

    tree .git /F

    （Windows 用 dir /s /b .git 或装个 tree 工具）
    你会看到大概这样：

    .git
│   HEAD
│   config
│   description
│   index      ← 暂存区（Staging Area）存放在这里
│
├───objects    ← 本地仓库存 commit、文件内容
├───refs       ← 分支引用
└───logs       ← 操作日志

    2. 暂存区（Staging Area）

    • 暂存区是一个 二进制文件，叫 .git/index。
    • 你 git add 之后，Git 会把文件的快照信息写进这个 index 文件。
    • 要看里面的内容，可以用：
    git ls-files --stage

    示例输出：

    100644 6f5902ac237024bdd0c176cb93063dc4 0       README.md
100644 8b1a9953c4611296a827abf8c47804d7 0       main.py

    这就是暂存区记录的文件及其 blob ID（指向文件内容在本地仓库的位置）。

    3. 本地仓库（Local Repository）

    • 本地仓库存放在 .git/objects 目录里。
    • 你每次 git commit，Git 会：
      1. 把文件内容存成一个个 blob 对象
      2. 把目录结构存成 tree 对象
      3. 把提交信息和 tree ID 存成 commit 对象
    • 这些对象以哈希值为文件名，保存在 .git/objects/xx/yyyyyy... 这种形式里。

    你可以用：

    git cat-file -p <对象ID>

    来查看内容，例如：

    git cat-file -p HEAD    # 查看当前分支的最新 commit

    它会显示：

    tree 5e3b6a...
parent a3dcb4...
author 你的名字 <你的邮箱> 时间戳
committer 你的名字 <你的邮箱> 时间戳

提交说明文字

    4. 实际观察流程

    比如：

    echo "hello" > test.txt
git add test.txt
git ls-files --stage   # 能看到 test.txt 已进暂存区
git commit -m "add test.txt"
git cat-file -p HEAD   # 查看最新 commit 的信息

    你会看到从工作区 → 暂存区 → 本地仓库的全过程。

    ✅ 总结：

    • 暂存区 = .git/index（可用 git ls-files --stage 查看）
    • 本地仓库 = .git/objects（可用 git cat-file 查看对象内容）

    仓库上传操作

    # 1. 初始化仓库（如果已经 init 过，可以跳过）
git init

# 2. 添加文件
git add {filename}

# 3. 提交一次（必要步骤，否则分支不存在）
git commit -m "初始提交：添加博客源码"

# 4. 把当前分支改名为 main
git branch -M main

# 5. 添加远程仓库地址
git remote add origin git@github.com:J-CLOWN-TAROT/BLOG_Backup.git

# 6. 推送到 GitHub
git push -u origin main
